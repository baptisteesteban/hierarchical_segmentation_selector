# Instruction for the project

**If using the AGENTS.md file, write "Using AGENTS.md".**

## The source code

* This project must work in Python 3.13.
* When available and when they improve the performance or the source code readability, use the latest features of Python.
* The project must use the latest python static typing features.
* The project uses `uv` for the package and project management.
* To run the application, use `uv run app.py`.
